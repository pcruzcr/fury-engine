# ADR-003 — Godot presentation layer (F2b)

Date: 2026-09-13 · Status: ACCEPTED · Owner: Principal Software Architect
Depends: ADR-001, ADR-002 · Closes (partially): ENV-001

## Context
F2b needed a verifiable presentation slice on the real 4.7.2 Mono binary without letting
visuals become simulation authority. Two integration unknowns existed: C# project location
vs the SDK's output layout, and headless verifiability.

## Decision
1. **Layout:** `src/Fighter.Godot/Fighter.Godot.csproj` (`Godot.NET.Sdk/4.7.2`, net9.0,
   ProjectReference → Fighter.Core). Assemblies MUST land in the project-root `.godot`
   (where the editor runtime scans). The SDK derives its output from `GodotProjectDir`
   evaluated in Sdk.props — too early for body-set values — so this project pins
   `GodotProjectDir` + absolute `BaseOutputPath`/`OutputPath` explicitly
   (lesson learned after two ignored attempts; verified via `msbuild -getProperty`).
2. **Sim authority:** exactly ONE `FightSimulation.Step` per `_PhysicsProcess` tick
   (physics is fixed 60 Hz; no accumulator, no delta). No `Engine.TimeScale` tricks
   anywhere near verification paths.
3. **Input map at runtime** (`InputMap.AddAction` in `_Ready`): no hand-authored `[input]`
   section, no untestable config strings. P1 keyboard (arrows + JKL/UIO); P2 scripted dummy.
   Parry chord (LP+MP) and block-hold work through the same actions.
4. **HUD/training from runtime truth only** (`TrainingText` reads `FighterData` via the live
   sim; input history via the read-only `GetHistory` accessor added for this purpose —
   presentation-only, never feeds simulation). Frame data, HP/EX/RES/state/move/hash on screen.
5. **VFX placeholders driven by `PresEvents`** (sparks/flash, frame-counted, cosmetic only).
   Audio deferred (no assets in F2b — explicit non-goal).
6. **Headless proof:** `res://scenes/Fight.tscn -- --auto-test` runs a scripted 600-frame
   Glen-vs-Kira match and asserts restore@300+resim AND full-replay hash equality IN-ENGINE,
   quitting 0/1. Run with `--headless --fixed-fps 60`. Evidence: hashA==hashB==hashC==PASS,
   empty stderr (2026-09-13).
7. **Export presets stay authored-but-unverified** (templates ~1.2 GB not installed;
   no signing infra). No export claim is made.

## Consequences
- ENV-001: import VERIFIED, in-engine build VERIFIED, headless run VERIFIED.
  Remaining: editor-GUI run (not required), template export (Beta).
- Visual polish must never mask sim defects (§82); the auto-test asserts sim truth, not pixels.
