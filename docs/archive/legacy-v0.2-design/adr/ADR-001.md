# ADR-001 — Technological baseline + F0 deterministic foundation

Date: 2026-09-13 · Status: ACCEPTED · Owner: Principal Software Architect

## Context
- Baseline audit (2026-09-13): empty repo (no commits, only `docs/` untracked). No sln/csproj/cs,
  no `project.godot`, no CI, no tests, no assets. Everything F0 was MISSING except design docs.
- Environment at audit: .NET SDK **8.0.425 only** (BLOCKING vs required .NET 9), runtimes 8 + 10,
  **no Godot editor binary** in PATH. Fixed during F0: installed `Microsoft.DotNet.SDK.9 9.0.318`
  via winget; runtime 9.0.20 present. Verified with `dotnet --list-sdks`.
- Design authority: GDD v8.0 canonical; v3/v4/v5/v7 = history/delta only (see 10-open-decisions DF-CON-001).
- Master Prompt hierarchy applies: Master Prompt → spec → design/canon → implementation → tests → evidence.

## Decision
1. **Engine:** Godot `4.7.2-stable` Mono family (ref `ed1daf0bf`). No `4.7-dev`/`4.8-dev`/`master` for production.
   Any upgrade needs impact + compatibility + determinism + test + build + perf validation.
2. **TFM:** `net9.0` everywhere (Android 16k alignment requirement). SDK 9.0.318 installed as part of F0.
3. **Architecture:** `Fighter.Core` (pure C#, zero `Godot.dll` — enforced by MSBuild `ForbidGodotReference`
   target + `CorePurityTests`) → `Fighter.Godot` adapters (F2) → GDScript UI/AI/tools only.
   `Fighter.Game` (match/mode rules) deferred to post-F0; F0 contains no game rules.
4. **F0 scope = deterministic substrate only:** SimulationUnits, Fixed Q16.16, Vector2I, SimulationClock
   (integer-µs accumulator; wall clock stays in presenter), InputState, RingBuffer&lt;8&gt;,
   DeterministicRng (SplitMix64), DeterministicSim stepper, StateSnapshot (schema 1, manual LE layout,
   324B payload), StateHasher (FNV-1a64, non-crypto), Replay (.DFRP v1).
   Combat/FSM/AABB/energy/characters explicitly deferred to F1. Resolver + resource seams exist
   as behavior-free interfaces (`NullCommandNormalResolver`, `IExPolicy`, `IResonancePolicy`) so
   OPEN questions are contained, not hardcoded.
5. **Godot integration in F0 = authored, NOT verified:** `project.godot` (4.7 schema, 60Hz physics,
   Forward+ / mobile Compatibility) and `export_presets.cfg` (Win/Linux/Android ARM64/iOS) are
   committed as text; editor import/run/export remain NOT TESTED until a 4.7.2 Mono binary exists
   in the environment (ENV-001). F0 gate therefore passes CONDITIONALLY on the Godot axis only.

## Consequences
- Core compiles and tests run with `dotnet` alone; Godot absence cannot break Core CI.
- Cross-platform determinism (PC vs Android ARM64) is a later gate (§55), not F0's criterion.
- Snapshot 324B + Capture+Hash avg **0.0327 ms** (Win10, 8 cores, 10k iters) — inside the 0.5 ms goal.
- MessagePack/LZ4 adoption stays OPEN pending benchmark (§64); current manual LE layout is the baseline.
